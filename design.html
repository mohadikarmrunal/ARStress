Three blocks, one stressor: losing the resource

A sketch of the laboratory session in which stress comes from the removal of the AR overlay or the paper manual, and not from the inspection task.

The principle. The task stays the same in every block: same pace, same pay rule, same board difficulty, no audience. What changes is whether guidance is there, and how sure people can be that it stays. Block 1 tells us how stressful the task is by itself. Anything above that level in Blocks 2 and 3 can be traced to the resource.

Open points

  • Paper outages. The overlay can be switched off by software. The manual needs an equivalent that works for a group, for example a covered document holder or a desk lamp switched by the PC.
  • Outages may teach coping. Practising short losses in Block 2 could soften the full removal in Block 3. Few and short outages limit this; the pilot data should show whether it happens.
  • Removal only matters if the task matters. The pay rule stays constant across blocks so that guidance is worth having, but it is never raised or announced anew.
  • Block 3 outages in C and D. They keep the threat alive in the control arms. Dropping them would give a calmer control but a less equal one.
  • Performance still carries part of the effect. Perceived performance and confidence after each block show how much.

Working sketch, not a protocol. Timings, counts and wording are placeholders.
